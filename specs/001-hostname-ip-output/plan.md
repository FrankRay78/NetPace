# Implementation Plan: Add Hostname and IP Address to Structured Output

**Branch**: `main` | **Date**: 2026-04-14 | **Spec**: [spec.md](spec.md)  
**Input**: Feature specification from `specs/001-hostname-ip-output/spec.md`

## Summary

Add `IPAddress` and `Hostname` fields to NetPace's JSON and CSV output to enable automatic correlation with Network Management System (NMS) device records. Implementation is Console-layer only: introduce an `IClientInfoProvider` abstraction (following the existing `IClock` pattern), register it in DI, inject into `SpeedTestCommand`, and populate the new output fields in `JsonConsoleWriter` and `CSVConsoleWriter`.

## Technical Context
