DESCRIPTION:
Show the nearest speed test servers.

USAGE:
    NetPace servers [OPTIONS]

OPTIONS:
    -h, --help       Prints help information.                                    
    -l, --latency    Include server latency in the results.                      
    -f, --fastest    Show the fastest server details, selected by lowest latency.
