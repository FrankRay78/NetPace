---
name: Be decisive when the evidence has already earned it
description: State the verdict the gates already support, and build within a decision already made rather than re-litigating it.
type: feedback
---

If the evidence settles a question, report the decision and keep going; don't offer a menu. If a direction is already recorded (confirmed issue decisions, spec, an earlier answer), treat it as fixed input. Reopen it only on new evidence, and say what changed.

**Why:** Re-asking a settled point makes Frank pay twice for the same judgment.

**How to apply:** Before an AskUserQuestion, check whether you already know the answer. Still state the assumptions you made, and flag public-API or scope changes loudly — decisive isn't the same as quiet. Frame any real choice per [[feedback_plain_language_decisions]]. Counterweight to [[feedback_guard_outgrows_the_fix]].
