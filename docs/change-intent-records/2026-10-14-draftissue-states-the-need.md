# `/draftissue` states the need, and an interface is an outcome

**Intent:** Record the maintainer's approval of the MINOR amendment to Constitution §IX that constitution 2.3.0's Sync Impact Report points here for. Principle IX's mechanism list banned naming the option, output field or exit code a CLI's users depend on, which is the very outcome such an acceptance criterion has to promise.

**Behaviour:** Constitution §IX, *Interface contracts are outcomes*, and `.claude/commands/draftissue.md`. Issue #369 carries the motivation and the acceptance criteria.

**Decisions:**

- *Maintainer approval for the §IX MINOR amendment: given by raising #369* — "raising this issue is that approval". The Amendment Process requires maintainer approval for a change to a principle, and this record is where the Sync Impact Report looks for it.
- *An interface contract is outcome, judged by who touches it.* Rejected: deleting the web-specific items from §IX's mechanism list, which would leave a web API's routes unclassified. The who-touches-it test covers both shapes, and the independence test already gave the same answer.

**Date:** 2026-10-14
